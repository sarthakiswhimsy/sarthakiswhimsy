### `~/projects/filetriage $ cat README.md`

**🔍 FileTriage — Self-Hosted Static Malware Analysis Platform**
Inspects uploaded files for malicious indicators without ever executing them — hashing, entropy analysis, YARA matching, ClamAV integration, IOC extraction, and a risk-scoring engine mapped to MITRE ATT&CK.

`FastAPI` `YARA` `ClamAV` `Docker`
