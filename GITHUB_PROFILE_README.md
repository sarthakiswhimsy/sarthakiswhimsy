A full-stack web app that lets defenders search any CVE, product, or keyword and instantly see severity, CVSS breakdown, and remediation guidance — cross-referenced live against CISA's Known Exploited Vulnerabilities catalog.
`Next.js` `Tailwind CSS` `NVD API` `CISA KEV` `Vercel`

A full-stack platform that inspects uploaded files for malicious indicators without ever executing them — hashing, entropy analysis, YARA signature matching, ClamAV integration, IOC extraction, and an explainable risk-scoring engine mapped to MITRE ATT&CK.
`FastAPI` `YARA` `ClamAV` `Docker`
